# Instrucciones para agentes

Antes de modificar cualquier archivo, lee `README.md` y `PROJECT.md`.

- No añadas dependencias sin justificarlo.
- No introduzcas funcionalidades fuera del alcance de la tarea.
- Mantén el código modular.
- Ejecuta `dotnet build` y `dotnet test` cuando exista código .NET.
- No hagas commit ni push salvo que se solicite expresamente.
- No modifiques `main` directamente cuando el desarrollo por ramas esté en marcha.
- Muestra siempre un resumen de cambios.
- Muestra errores o limitaciones reales.
- No guardes claves, tokens, contraseñas ni credenciales.
- Evita comandos destructivos.
- Pide confirmación antes de eliminar archivos.
- Mantén la documentación sincronizada con cambios importantes.
