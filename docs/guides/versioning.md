# Versionado

KernelOS adopta Semantic Versioning: `MAJOR.MINOR.PATCH`. Durante el desarrollo inicial, `0.x.y` indica que el producto sigue siendo inestable. `MINOR` representa un milestone o capacidad compatible; `PATCH`, una corrección compatible; `MAJOR`, una ruptura importante cuando exista una API estable.

La versión actual es `0.4.0`, centralizada en `Directory.Build.props`. Solo se actualizará al cerrar milestones:

- `0.1.0`: Foundation.
- `0.2.0`: Chat y Tool System.
- `0.3.0`: Planner Core.
- `0.4.0`: Filesystem Read Only.

Este documento no crea tags, releases ni paquetes.
